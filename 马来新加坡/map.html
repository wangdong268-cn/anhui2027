01 / ROUTE

吉隆坡进，新加坡出

北京红眼到吉隆坡，市区一天；包车去布城、马六甲、新山；乐高乐园一天，再从新山过关到新加坡；动物园、圣淘沙、市区，樟宜机场回。

路线骨架
北京 → 吉隆坡 → 布城 → 马六甲 → 新山 → 新加坡 → 北京。

节奏
7 天 6 晚；亚航红眼、Grab、新山过关大巴、新加坡地铁 + Gocity 通票；榴莲季没到，是最大遗憾。

02 / WHY

为什么是新马

疫情后第一站，选个简单、飞行不太久、孩子有得玩的地方。乐高、动物园、圣淘沙、樟宜机场，刚好一条线。

01

红眼省时间

亚航便宜，红眼航班熬一晚，第二天一早就能逛；打工人假期少，能省一天是一天。

02

乐高和动物园

新山乐高 land + sea + water park，人不多；新加坡动物园、飞禽、河川，孩子可以玩两天。

03

城市和机场

吉隆坡双子塔、马六甲、圣淘沙、滨海湾；樟宜机场多留时间，瀑布、小火车、大滑梯。

03 / DAY BY DAY

七天，四城特种兵

红眼、包车、过关、地铁、缆车；每天都是满的，但孩子有得玩，大人也吃到了。

第一段 · 吉隆坡、马六甲、新山

4.29—5.1

国博、双子塔、布城、马六甲、乐高。

4.29
D1 · 北京—吉隆坡
亚航 → 吉隆坡 → 国博 → 国家清真寺 → 双子塔红眼落地，直接开逛。

红眼到吉隆坡，先吃华阳冰室

亚航 2:30 出发，7kg 行李；队友又高又胖，直呼廉航不能再坐。晚点一小时，9:30 落地吉隆坡。

机场华阳冰室吃广式茶餐厅，和香港的逛搭子一家连线；打车去国家博物馆，娃评价此行最差——四个展厅，只有一楼有空调。

国家清真寺、占美清真寺；太热，走几百米都很辛苦。回武吉免登酒店换衣服，海脚人吃饭；榴莲季没到，榴莲店都不开门。

晚上步行柏威年，走链接长廊去双子塔，公园里孩子玩水；大暴雨，来自内陆人的无知，以为下不长。

行亚航红眼吃华阳冰室 / 海脚人住Sleeping Lion 327提醒榴莲季没到
4.30
D2 · 吉隆坡—布城—马六甲—新山
粉红清真寺 → 马六甲 → 水上清真寺 → 新山包车一日游。

马六甲，从书里变成现实

包车去马六甲，先到粉红清真寺；网红机位实拍没有那么粉。马六甲一日游点基本固定：荷兰红屋、圣保罗山、旧皇宫、鸡场街、娘惹博物馆、三保庙。

对我们来说，更多是书上马六甲变成现实的情怀；其实都变旅游地，看不到真正的海峡，来不来尚可。

下午四点多往新山，又去了海上清真寺，堵车七点半到；打车去吃榴莲，五一不是季节，只有泰国金枕，猫山王是冻的，价格还高。

对面田鸡粥，广式粥铺；住 Fives，步行过关方便。

玩粉红清真寺 / 马六甲吃娘惹小厨 / 榴莲住Fives 631提醒包车点位
5.1
D3 · 新山乐高
乐高 Land / Sea / Water Park人不多，排队 5—10 分钟。

乐高乐园，三个园一天

Land 和 Sea 在一起，穿过海洋馆就是一条街；海洋馆一般，有套票快速看半小时。乐园更适合低幼，过山车也不怕。

人流量正好，不多不少，排队 5—10 分钟；中午乐高大街吃套餐，下午水上乐园，储物柜小 20、大 30。

晚上又去昨天的榴莲摊，开门的太少；芽笼田鸡粥、榴莲，回酒店。

玩乐高三园吃炸鸡饭 / 田鸡粥住Fives提醒水上储物柜

第二段 · 新加坡：动物园、圣淘沙

5.2—5.4

新山过关，飞禽/动物园/河川，圣淘沙环球，滨海湾和市区。

5.2
D4 · 新山—新加坡动物园—滨海湾
兀兰过关 → 飞禽 → 动物园 → 河川 → 滨海湾过关大巴 CW1。

四个动物园，和滨海湾夜景

从酒店对面商场过关，跟着 Woodland 标志走；提前准备过关材料，坐 CW1，现金 2.6 新币/人，送到地铁站。

新加坡动物园这片有四个：动物园、河川、夜间、飞禽；飞禽远，要坐摆渡车；其他三个挨着。夜间要邮件预约，我们放弃，改去滨海湾。

飞禽的印度餐厅吃不惯，一份小 30 新币；园区直饮水省了不少买水钱。

晚上滨海湾花穹、天空树表演、金沙、双螺旋桥；看着不远，走起来挺累。

玩飞禽 / 动物园 / 河川 / 滨海湾吃印度菜 / 大排档住Studio M 2,134提醒夜间预约
5.3
D5 · 圣淘沙
缆车 → 天际滑车 → 大秋千 → 环球 → 时光之翼特种兵的一天。

圣淘沙，从早玩到晚

地铁到港湾站，缆车进岛；先反向往花柏山，再从高处看，然后坐到岛上。天际滑车买四圈，第一次新手通道，之后盖章走老手通道。

大秋千对身高体重要求严格，妹妹不能玩，去沙滩；岛上交通免费，地铁、巴士、小火车。环球下午排队，红黑过山车坐了两次，木乃伊、侏罗纪、靴子猫。

7:15 出来，7:45 时光之翼水幕秀；缆车回港湾，地铁牛车水大食堂吃饭，回酒店泳池。

玩环球 / 滑车 / 时光之翼吃牛车水住Studio M提醒环球关门时间
5.4
D6 · 新加坡市区
鱼尾狮 → 鸭子船 → 观光巴士 → 牛车水 → 樟宜机场大雨，city walk。

鱼尾狮、鸭子船和樟宜机场

一起来就大雨，幸亏是最后一天 city；先打车鱼尾狮打卡，大雨天没人；新达城坐鸭子船，晴天景色一定更好。

观光巴士 24 小时随上随下，红线经过小印度、牛车水、甘榜格南、哈芝巷、回教堂；牛车水佛牙寺、印度庙。

樟宜机场多留时间：T2 电子瀑布、T2—T3 小火车穿瀑布、T3 大滑梯；回程马尼拉转机，行李直挂。

玩鱼尾狮 / 鸭子船 / 樟宜吃松发 / 大胡子住飞机上提醒机场留时间

04 / FAMILY

乐高、动物园、圣淘沙

新马这条线适合带娃：乐高人不多，动物园四个园，圣淘沙从早玩到晚，樟宜机场本身就是一个景点。

“榴莲季没到，是这次最大的遗憾；但四个人的特种兵行程，值了。”

Land + Sea + Water

三个园一天，人不多，排队 5—10 分钟；水上乐园储物柜小 20、大 30。

四个园

07 / NOTES

新马带娃，记住这些小事

红眼、过关、通票、机场；提前准备材料，别在值机柜台被卡住。

01

入境卡提前 3 天

马来西亚入境卡官网填，提前 3 天；0 点以后入境算第二天。

02

新山过关材料

亚航值机会查离开马来西亚的凭证；新山—新加坡大巴票提前网上买，现场买不固定时间。

03

护照盖章

注意海关是否盖章；自助通道信息可能不同步，出关被查麻烦；乖乖扣章。

04

支付

招行 visa 信用卡可坐地铁；现金不用多，100 多马币都没花完；部分支持支付宝。

05

流量

移动国际流量 7 块多/天，3G 够用；没买当地卡，少了当地号码。

06

Gocity

新加坡通票含环球、动物园等；鸭子船、夜间动物园要提前预约。

07

樟宜机场

多留时间：T2 瀑布、T2—T3 小火车、T3 滑梯；回程马尼拉转机行李直挂。

08

榴莲

五一不是榴莲季，很多店不开；新山只有泰国金枕，猫山王是冻的；想吃榴莲，换个季节再来。

后记

疫情后第一站，选个简单的东南亚；下一次，把印尼和榴莲季一起补上。
