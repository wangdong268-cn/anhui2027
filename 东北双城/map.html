02 / WHY

为什么是东北双城

秉着一个省一个省的原则，先把东三省补齐。长春和沈阳 2019 年短暂停留过，这次把缺的点补上；顺便把东北的早市、烧烤和洗浴都体验一遍。

01

一个省一个省地走

东三省先补齐。长春和沈阳都去过，但只是短暂停留；这次把伪满皇宫、长影、九一八、工业博物馆、沈阳故宫、大帅府、辽博这些点串起来。

02

一条博物馆线

伪满皇宫看末代皇帝，长影看电影史，省博 / 科技馆 / 光学馆一个门三个口，九一八和工业博物馆看近现代东北。行程不轻松，但值得。

03

烧烤四连

每天晚上都是烧烤，连吃四天，各有各的口味。没有追求网红店，找本地人多的就行；铁岭生串、沈阳的茄子都让人惦记。

03 / DAY BY DAY

五天，把历史补上

不赶打卡，先把每天最重要的博物馆或街区走完。剩下的时间，留给早市、烧烤和路边偶遇。

D0
4.30 · 北京—长春
北京 → 长春动卧，晚上上车，早上到；不占白天。

动卧去长春，睡一觉就到

这次去程是动卧。晚上从北京上车，睡一觉，5.1 早上到长春；具体车次按 12306。比起白天高铁，动卧不占白天，到了就能开始玩。

回程不坐火车，而是自驾回北京。提前在 12306 上订了租车：长春这有山取车，北京回龙观还车，3 天 5 小时，839 元，没有异地还车费，也不用担心买返程票。

D1
5.1 · 长春
长春西 → 新天地 → 伪满皇宫打车到新天地吃饭；下午伪满皇宫。

新天地、伪满皇宫，和一顿不太好吃的锅包肉

早上到长春西，打车到新天地，先吃饭。大商场里有很多吃的，选了个锅包肉，但是不好吃，不推荐。最有意思的是“威尼斯人平替”，室内划船，大小同价 15 元/人，很短，就是个体验。

接着打车到伪满皇宫博物院，了解末代皇帝，也了解东三省在近代史上的事件。伪满皇宫和长影可以买联票，比较划算；东北陈列馆地理位置上和伪满又挨着，可以两个一起看。

出来后在酒店周边找了个小馆子吃烧烤。当地大哥都说别去网红，小店老店都不错。

住全季长春 · 258 吃姬大厨 / 烧烤 玩新天地 / 伪满皇宫 提醒锅包肉不推荐
D2
5.2 · 长春—铁岭
省博 → 科技馆 → 光学馆 → 长影 → 这有山 → 铁岭取车后开去铁岭。

一个门进三个馆，下午长影，晚上铁岭生串

省博、科技馆、光学馆在一起，一个门进去，三个口。科技馆里全是孩子，可以体验项目，很大；远处就是长春影视城，游乐场。

三个馆出来直接去了长影，怕关门，也没有去别处，就在对面的萍乡大厨吃了午饭，抓紧进长影。电影开场标志打卡；里面的内容感觉没有电影博物馆得好，但情怀和历史在里面加持。

出来后对面就是观光有轨电车，票价分好几种；普通票坐两站体验一下就好，观光的价格高，但氛围好。过一个路口，看到人乌泱乌泱的，就是这有山了；巨大的商场，人太多，消防通道也不明显，挺害怕的，打个卡撤了。

晚上到宇宙中心铁岭。据说当天有小柔师妹来这里，但是到得晚了，没跟上看。特别喜欢铁岭的生串，遗憾的是有名的几家全都卖光了，找了个看着人多的，也挺好；饭后泡澡，136 元/人。

住铁岭天兴 · 266 吃萍乡大厨 / 生串 玩省博三馆 / 长影 / 这有山 行取车去铁岭
D3
5.3 · 铁岭—沈阳
彩虹桥早市 → 银冈书院 → 铁岭博物馆 → 九一八 → 工业博物馆下午到沈阳。

早市、银冈书院，和雨里的九一八

一家子早上起不来，早市成了奢侈；刚好铁岭住得离彩虹桥早市不远，赶紧去体验一把。当天可能是个良辰吉日，酒店下面公告牌上全是结婚的。东北早市，从头吃到尾。

银冈书院是周总理儿时读书的地方，和铁岭博物馆在一起，可以一起转。去铁岭火车站路上路过铁岭名人推荐过的火勺，小号的肉烧饼；打卡同款铁岭站。起得太早赶早市，路上熬不住了，全体歇了一会。

中午到沈阳，先去路比较顺的九一八。本来人就多，加上响雷飘了点雨，人群就乱了，急了，都往里冲，好多还都是年纪大的，不管不顾就挤。出来后去工业博物馆，会路过几个文化街区，没太大兴趣就直接过。晚上烧烤，平平无奇的茄子都特别好吃。

住全季沈阳开发区 · 359 吃早市 / 小二牛烧烤 玩银冈书院 / 九一八 / 工业博物馆 提醒雨天排队
D4
5.4 · 沈阳—绥中
沈阳故宫 → 大帅府 → 辽博 → 绥中晚上开到绥中看海。

故宫、大帅府、辽博，然后去看海

故地重游。2019 年来的时候随便进，现在排队都排不上。中街、故宫、大帅府走路可达；现在人太多，转圈排队，还没进去先绕两公里，里面每个殿门口又是转圈圈。

只能在拥挤的人群中，抬高手臂拍一张，稍微停留，保安就会喊“拍完赶快走”。看清楚、看历史？不存在的，拍完赶紧走，观感度为零。

出来打车去省博，司机大哥说这都算人少的了，只是堵但还能走动，前两天车根本动不了。省博不需要预约，但是儿童体验馆要预约；两娃大了兴趣不大，就没预约。晚上往回开了点，到绥中看看海；汉庭绥中 225，大鹏烧烤 210。

住汉庭绥中 · 225 吃米线 / 大鹏烧烤 玩沈阳故宫 / 大帅府 / 辽博 提醒五一排队
D5
5.5 · 绥中—北京
绥中 → 北京海边随便玩；下午错峰返程。

海边写作业，错峰回京

当天天气不好，加上还有个初中生作业需要收尾，就海边随便玩了玩，返程。海鲜市场买了螃蟹，包子、方便面补齐路上的胃。

返程路上很顺，没有堵车。还担心最后一天会不会车很多，据说好多车都堵在了 4 号，5 号下午反而一路畅通。顺利返京。

04 / MUSEUMS & BBQ

白天看历史，晚上吃烧烤

这次的重点不是打卡，而是把 2019 年没来得及看的几个点补上；博物馆安排得密，但每个都值得。晚上则统一交给烧烤。

“一个省一个省地走，先把东三省补齐。”

伪满皇宫 + 长影

联票 129 × 2

末代皇帝与东北近代史；长影是电影情怀，内容不如电影博物馆，但历史加持。两处距离不远，联票更划算。

省博 / 科技馆 / 光学馆

一个门，三个口

科技馆里全是孩子，体验项目多、空间大；省博和光学馆可以顺路。适合安排半天，别低估孩子的体力消耗。

九一八 / 工业博物馆

免费 · 人多

九一八人多，雨里排队容易乱；工业博物馆看东北工业的骨架。两个都不轻松，但都是理解这座城市的入口。

07 / NOTES

五一北上，记住这些小事

东北的五一，白天看历史，晚上吃烧烤；人多、车多，但错峰和地铁能把体验拉回来。

01

动卧 + 12306 租车

去程北京—长春动卧，睡一觉就到；12306 租车活动，长春取车、北京回龙观还车，没有异地还车费，也不用买返程票。

02

五一别开车进沈阳景点

沈阳景点附近超级堵，车停两三站地铁外，再坐地铁过去；打车也寸步难行。司机大哥说 4 号已经好很多了。

03

博物馆预约

这次博物馆预约弱化了，基本现场约或者不约都行；辽博儿童体验馆要预约，伪满皇宫 + 长影联票更划算。

04

烧烤找本地人多的

连吃四天烧烤，各有各的口味；不追网红店。铁岭生串、沈阳的茄子、绥中的大鹏，都是本地人多的选择。

05

早市要早起

彩虹桥早市值得去，但一家子容易起不来；住近一点，赶在收摊前从头吃到尾。火勺是小号肉烧饼，路过别错过。

06

这有山打卡就走

人乌泱乌泱，消防通道也不明显；带娃不建议久留，拍张照就撤，把时间留给博物馆和烧烤。

07

九一八带伞、避开高峰

人多加雷雨，入口容易乱；带伞，尽量避开团队高峰。工业博物馆可以顺路，但别安排得太满。

08

返程错峰

5.5 下午反而一路畅通；好多车堵在 4 号。回京前加满油，海边玩完直接上高速，别赶在傍晚进城。
