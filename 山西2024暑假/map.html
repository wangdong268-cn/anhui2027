01 / ROUTE

从晋北到晋南，跟着梁林看古建

北京自驾出发，先到繁峙看正觉寺、公主寺、佛光寺、南禅寺；再沿平遥、介休、隰县、侯马一路南下，以运城为基地，看芮城、万荣、夏县、永济；返程补广胜寺和太原北齐壁画。

02 / WHY

为什么是山西

去年十一在运城看了 7 天，没看够。暑假的山西人少、凉快、花费少，很多小寺小庙可以安安静静地看，甚至包场。

01

跟着梁林看古建

佛光寺、南禅寺、双林寺、小西天、永乐宫、广胜寺；从唐构到明清，从彩塑到壁画，一条线看下来。

02

人少凉快

暑假的山西比南方凉快，古建大多在村里、山上；人不多，能靠近看斗拱、悬鱼、琉璃，体验比热门景区好。

03

花费少

门票便宜，很多点免费或年卡；吃住也实在。10 天 2 大 2 小，总花费 4,413.17 元。

03 / DAY BY DAY

十天，从晋北看到晋南

古建看门、彩塑看光、壁画看运气；每天一两个重点，剩下的随缘。

第一段 · 晋北：繁峙、五台、平遥

7.12—7.15

正觉寺、公主寺、佛光寺、南禅寺、双林寺、镇国寺、小西天。

7.12
D0 · 北京—繁峙
北京 → 繁峙下午出发，晚上到。

出发，第一站繁峙

中午约 4 点从北京出发，高速晚上 9 点到繁峙，简单住下；到的早可以去憨山景区，之前免费，今年开始收费。

行北京—繁峙吃老地方烧烤住繁峙 81提醒早到可逛憨山
7.13
D1 · 繁峙—祁县
正觉寺 → 公主寺 → 佛光寺 → 南禅寺 → 忻州古城梁林路线的重头戏。

佛光寺，千年一寺

繁峙本地人读“si”，山多、寺多。城里选正觉寺，看房顶、经幢、悬鱼惹草；公主寺运气好，门开着。

重头戏是佛光寺，清华讲解的“千年一寺”，林徽因照片里的经幢；转间铺作两米多高。南禅寺是三座半唐构中最早的。

晚上到忻州古城，明码标价，放心吃。

玩佛光寺 / 南禅寺吃忻州古城住祁县汉庭 149提醒必去佛光寺
7.14
D2 · 祁县—隰县
双林寺 → 镇国寺 → 介休 → 王家大院 → 隰县彩塑、琉璃、大院。

双林寺的韦陀，和介休的琉璃

放弃平遥古城，选双林寺、镇国寺。双林寺四大天王、自在观音、最帅韦陀，眼珠子特别亮；千佛殿千手观音。

介休一定要看琉璃：祆神楼、后土庙，孔雀蓝在晴天更好看；非饭点没吃的，一定要看饭点。

灵石王家大院，山西第一宅；请个讲解，山西归来不看院。

玩双林寺 / 镇国寺 / 王家大院吃介休饼子住隰县 88提醒饭点
7.15
D3 · 隰县—侯马
小西天 → 蒲县东岳庙 → 侯马悬塑绝唱；大雨放弃广胜寺。

小西天，悬塑绝唱

小西天是必须之必。200 多级台阶，九九八十一阶，进殿看天宫楼阁；到的早人少，可以靠近慢慢看，11 点后研学团一来就吵。

午饭隰县羊汤；下午蒲县东岳庙，除了我没有游客，安静得有点怕。地狱部分黑黑的，十八层地狱各种刑罚，胆小慎入。

本来去洪洞广胜寺，大雨大雾，高速能见度差，放弃，直接侯马聚餐；路边侧翻大车，安全第一。

玩小西天 / 东岳庙吃隰县羊汤住侯马汉庭提醒早去小西天

第二段 · 运城：芮城、万荣、夏县、永济

7.16—7.20

以运城为基地，看永乐宫、广仁王庙、李家大院、堆云洞、关帝圣像。

7.16
D4 · 侯马—运城
稷王庙 → 大佛寺 → 马村砖雕墓 → 李家大院下墓；李家大院看善。

稷王庙、砖雕墓和李家大院

稷山稷王庙保存最完整、最大，三绝：木雕、石刻、琉璃；大佛寺没游客，居士讲解；青龙寺壁画很绝，可惜关闭。

马村砖雕墓，经典的妇人启门；下墓没人有点怕，问讲解说有两拨人，结果电话一接游客都上来了，只能大胆下墓。

万荣李家大院，看善行善举；秋风楼、后土祠、飞云楼没去，留个下次。

玩稷王庙 / 砖雕墓 / 李家大院吃稷山饼子 / 羊肉泡住运城提醒青龙寺关闭
7.17
D5 · 运城—芮城—运城
广仁王庙 → 永乐宫 → 城隍庙 → 大禹渡 → 圣天湖黄河边，空无一人的景区。

永乐宫，和黄河观景台

早市买早饭回来，加上头天娃们逮的知了猴，秒回童年。广仁王庙免费，登记即可；永乐宫年卡，阴雨天殿里黑乎乎，还是不让拍照。

寿圣寺关了，只能外围看；城隍庙一下看四个朝代的建筑；大禹渡、望河楼看黄河，两三分钟后云飘过来什么都看不到。

圣天湖空无一人；田里成片扔掉的油桃，产地收购价低，摘都不摘。

玩永乐宫 / 城隍庙 / 黄河吃早市 / 熟肉住运城提醒永乐宫不让拍
7.18
D6 · 运城—万荣—运城
李家大院拍照 → 盐池 006 → 盬街 → 小石岛书店终于天晴。

天晴，去李家大院拍照

接连阴雨，这一天终于天晴，抓紧又去李家大院给两姑娘拍照；盐池公路 006 号路杆成了网红打卡地，还专门修了台子。

盬街、小石岛书店小聚；以前总路过，没想到成了打卡地。

玩李家大院 / 盐池吃古街夜市住运城提醒拍照 350

D7 · 运城—夏县—运城
堆云洞 → 司马温公祠 → 黄河夜市走亲戚，吃夜市。

堆云洞和司马光

早走亲戚，午饭聚餐；下午夏县堆云洞，有早期革命地址；司马温公祠，夏县最著名的人物司马光。

晚上黄河夜市，运城娃娃们都懂。

玩堆云洞 / 司马温公祠吃黄河夜市住运城提醒走亲戚
7.20
D8 · 运城—永济—运城
关帝圣像 → 扁鹊庙 → 永济 → 牛肉饺子全牛宴；关帝圣像。

关帝圣像和永济

关帝圣像景区，60 米高的圣像，建议上去坐摆渡车，下来溜达；运城还有解州关帝庙、常平家庙，时间够可以一起。

下午永济办事，路过扁鹊庙，一进门中药味；永济可以看鹳雀楼、黄河大铁牛、普救寺、风陵渡。晚上晓雪牛肉饺子。

玩关帝圣像 / 扁鹊庙吃全牛宴 / 牛肉饺子住运城提醒摆渡车

第三段 · 返程：广胜寺与北齐壁画

7.21

补上广胜寺和太原北齐壁画，半夜到京。

7.21
D9 · 运城—北京
广胜寺 → 太原北齐壁画 → 北京琉璃宝塔；壁画。

广胜寺，和北齐壁画

6:30 出发，广胜寺琉璃宝塔 8 月围起来修，去之前看开没开；飞虹塔名声在外，上寺下寺的泥塑、壁画也很好。摆渡车上山，从上寺走下来。

下寺壁画被扣走卖掉，现在在美国大都会、纳尔逊博物馆，只剩空白。太原北齐壁画博物馆，赶上 3 点公益讲解；马的眼睛，无论哪个角度都像在看你。

吃完饭返京，半夜到；山西一定要注意饭点。

04 / HERITAGE

从唐构到悬塑，一次看个够

佛光寺、南禅寺、双林寺、小西天、永乐宫、广胜寺、北齐壁画；这条线把山西古建最精华的一段串起来。

“地上山西，地下陕西；山西古建，越看越上头。”

佛光寺

唐 · 千年一寺

梁林路线的重头戏；东大殿、经幢、两米多高的转间铺作。看清华讲解，也可以读古建筑的书。

南禅寺

唐 · 三座半唐构最早

规模不大，但年代最早；和佛光寺一起看，唐构的两种气质。

双林寺 / 小西天

彩塑 · 悬塑

双林寺的韦陀、自在观音；小西天的天宫楼阁、悬塑绝唱。都要早去，安静地看。

永乐宫 / 广胜寺

壁画 · 琉璃

永乐宫壁画不让拍照；广胜寺飞虹塔、上寺下寺泥塑壁画；下寺壁画流失海外，只剩空白。

07 / NOTES

看古建，记住这些小事

山西古建分散、开门靠运气；自驾、看饭点、随缘，心态好最重要。

01

自驾

古建位置分散且偏，公共交通不便；自驾最方便，村路慢一点。

02

饭点

山西饭店过了饭点真没吃的；介休、运城都踩过；一定要看饭点。

03

文保员

很多寺平时锁着，门口有电话；打过去几分钟就来，热情讲解；看完说谢谢。

04

拍照规则

不用闪光灯、强光，简单拍照放开；永乐宫仍然不让拍；遵守规则。

05

提前学

硬山悬山歇山庑殿、斗拱昂杪耍头、三圣三清；不懂也会被震撼，但懂一点更好看。

06

年卡

运城年卡可省门票；永乐宫、李家大院、关帝圣像等可用。

07

广胜寺

飞虹塔 8 月围起来修，去之前看开没开；摆渡车上山，从上寺走下来。

08

随缘

古建太多，资金人员不到位；开门靠运气，别避雷，随缘。

后记

地上山西，地下陕西；
山西古建，越看越上头。

两次假期也只是从南到北挑着看；西边沿黄公路、东边晋城长治，留个下次。
